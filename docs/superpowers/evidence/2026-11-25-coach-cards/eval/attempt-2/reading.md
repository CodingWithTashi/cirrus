## One thing the bar does not see

The eval gives both models the same card. Production does not. While
`COACH_UI_AUDIENCE` is `premium`, the craving log is read only for
subscribers and trials, and they are answered by the premium model. A free
account, which is the lite model, gets no craving-log lines. It would get
the danger-hour line, the last-puff line, and the just-did line only if the
app sent one. So lite's misses above are measured on a card lite would
receive only if the audience were widened to `all`, or `AI_COST_PANIC` sent
subscribers to the lite model.

That is checked in the server code (which model answers which tier, and when
the cravings are read). Whether a free account's app ever sends a just-did
is not something the server decides and was not checked here.

It does not change the verdict: the bar asks for each model separately on
this card, and lite misses it. It is a reason to decide, before any further
roll, whether lite should be graded on the card it is actually given.
